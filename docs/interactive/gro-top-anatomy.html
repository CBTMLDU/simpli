The coordinate file — conf.gro

Fixed-width like the PDB, but with its own column layout and — importantly — nanometres instead of Ångströms.

  • title
  • atom count
  • residue
  • atom
  • coordinates
  • box vectors

A .gro file is fixed-width: column position is the syntax, exactly as in a PDB.

The topology file — topol.top

Not fixed-width — organised into directives written in square brackets. This file contains no 3D structure at all. It describes what the system is, never where it sits. 

#include "charmm36-jul2022.ff/forcefield.itp"

[ moleculetype ]
; Name            nrexcl
Protein_chain_A     3

[ atoms ]
;   nr  type  resnr residue  atom   cgnr   charge     mass
     1    NH3      1    SER      N      1   -0.300  14.0070
     2     HC      1    SER     H1      2    0.330   1.0080

[ bonds ]
;  ai    aj funct
    1     2     1
    1     3     1

[ angles ]
;  ai    aj    ak funct
    2     1     3     1

[ dihedrals ]
;  ai    aj    ak    al funct
    1     5     7     9     9

#include "charmm36-jul2022.ff/tip3p.itp"
#include "charmm36-jul2022.ff/ions.itp"

[ system ]
Protein in water

[ molecules ]
; Compound        #mols
Protein_chain_A       1
SOL                 618
NA                    3
