Weight arriving in state B, divided by time. The dashed line is the true rate for this barrier. Log scale — each gridline is a factor of ten, so landing within a factor of a few of the line is a good short run.

Watch the ensemble creep to the right. No walker is ever pushed. When one strays into a thinly populated bin it is copied, and the copies split the parent's weight between them — so there are more trajectories where the interesting things happen, and each one counts for less.
What is conserved and what is not. Every walker runs plain unbiased dynamics on V(x) = h(x² − 1)² — no bias potential anywhere, and both modes run a comparable number of walkers. Splitting divides a walker's weight between its copies; merging adds two weights together. Total weight stays at exactly 1, which is why the flux into state B is a real rate and not a rescaled one. Walkers reaching B are returned to A carrying their weight, so the ensemble measures steady-state flux.
