Each line is one instruction. Anything you leave out takes its default value.

This particular file is close to a formality — genion never runs a simulation. But the same format, with different values, drives every stage that follows.

Generate the packaged file with gmx grompp -f ions.mdp -c solvated.gro -p topol.top -o ions.tpr, then hand it to gmx genion.
